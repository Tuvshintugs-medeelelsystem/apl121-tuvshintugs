# APL121 Бие даалт №1 — Code Quest

## Сэдэв 4: сарын цахилгааны тооцоо

### 1. Оюутны мэдээлэл

- **Хичээл:** APL121
- **Бие даалт:** Code Quest
- **Сэдэв:** 4 — цахилгааны төлбөр
- **Оюутны нэр:** Б.Түвшинтөгс/B26FA1314/
- **Групп:** 1-408

### 2. Програмын зорилго

Энэхүү програм нь 12 сарын цахилгааны хэрэглээг киловатт-цагаар (kWh) авч, шаталсан тарифын дагуу сар бүрийн төлбөрийг тооцоолно. Мөн жилийн нийт төлбөр болон хамгийн их цахилгаан хэрэглэсэн сарыг тодорхойлж, цахилгаан хэмнэх зөвлөмж өгнө.

### 3. Цахилгааны тариф

Програмд дараах тарифыг ашиглана:

- 0–150 kWh: 1 kWh тутамд 120 төгрөг
- 150-аас дээш–300 kWh: эхний 150 kWh-д 120 төгрөг, үлдсэн хэрэглээнд 180 төгрөг
- 300 kWh-аас дээш: эхний 150 kWh-д 120 төгрөг, дараагийн 150 kWh-д 180 төгрөг, үлдсэн хэрэглээнд 250 төгрөг

Төлбөрийг шатлал тус бүрээр тооцно.

### 4. Програмын боломжууд

- 12 сарын цахилгааны хэрэглээг оруулах
- Сар бүрийн төлбөрийг шаталсан тарифаар бодох
- Сарын мэдээллийг хүснэгтээр харуулах
- Жилийн нийт төлбөрийг тооцоолох
- Хамгийн их хэрэглээтэй сарыг тодорхойлох
- Сөрөг утгатай оролтыг шалгаж, дахин оруулах
- Цахилгаан хэмнэх зөвлөмж хэвлэх

### 6. Програмыг ажиллуулах

GCC суулгасан орчинд `bd1` хавтас руу орж дараах командыг ажиллуулна.

**Компиляц хийх:**

```bash
gcc -Wall main.c -o main
```

**Linux/macOS дээр ажиллуулах:**

```bash
./main
```

**Windows дээр ажиллуулах:**

```bash
main.exe
```

### 8. Жишээ гаралт

Дээрх жишээ оролтын дагуу:

- Жилийн нийт төлбөр: **412,700 MNT**
- Хамгийн их хэрэглээ: **7-р сар**
- Хамгийн их хэрэглээний хэмжээ: **400 kWh**
- Тухайн сарын төлбөр: **70,000 MNT**

### 9. Туршилт

Програмыг дараах тохиолдлуудаар туршина:

1. Бага хэрэглээ — 100 kWh
2. Тарифын зааг — 150 kWh
3. Хүчингүй оролт — -50 kWh
4. Дунд шатлал — 200 kWh
5. Өндөр хэрэглээ — 350 kWh

### 10. AI ашигласан тухай

AI-ийг тарифын логик, нөхцөл шалгалт болон програмын алдааг ойлгоход, олоход ашигласан. Програмын код, pseudocode болон Flowgorithm диаграммыг өөрийн ойлголтод тулгуурлан боловсруулж, туршилтаар шалгасан.
